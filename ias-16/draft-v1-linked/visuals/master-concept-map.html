Models

4.0Subsequent models

4.1Policy by entire class

  • Choose the cost model or the revaluation model as accounting policy, and apply that policy to an entire class (similar nature and use).
  • If the revaluation model is used for an item, revalue the entire class.
  • Revalue the class simultaneously. Rolling only if the whole class is finished within a short period and kept up to date.

4.2Cost model

Carrying amount = cost − accumulated depreciation − accumulated impairment.

4.3Revaluation model

Carrying amount = revalued amount (fair value − subsequent accumulated depreciation − subsequent accumulated impairment).

Sufficient regularity so the carrying amount does not differ materially from fair value.

4.4Eliminate accumulated depreciation, or restate gross — same net carrying amount.

4.5Increase → other comprehensive income, except a reversal of a decrease already in profit or loss. Decrease → profit or loss, except an existing surplus. Same asset only.

4.6Surplus is transferred to retained earnings, not through profit or loss.
