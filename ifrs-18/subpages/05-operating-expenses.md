## Teaching sections

### 5.0 Scope of this chapter `{#s-5-0}`

Inside the operating category, present expenses so the operating band remains a useful structured summary — by nature, by function, or mixed. Function presentation triggers cost-of-sales (when applicable) and a single-note nature totals disclosure. **§78–85**, **B78–B85**

> **Pitfall:** Teaching “pick nature or function forever for every line.” Mixed is allowed: each line uses one basis, but not all lines need the same basis. **§79**, **B81**

### 5.1 Selection cue — most useful structured summary `{#s-5-1}`

In the operating category, classify and present expenses in line items in a way that provides the most useful structured summary, using one or both of: **§78**

- the nature of expenses; or

- the function of the expenses within the entity.

| Option | Teaching paraphrase | Cite |
|---|---|---|
| Nature | Resources consumed (materials, employee benefits, depreciation, amortisation…) without mapping to activity | **§80** |
| Function | Allocate/aggregate by activity (e.g. cost of sales, R&D) — may mix natures inside one function line | **§81** |
| Mixed | Each individual line uses only one characteristic; different lines may use different characteristics | **§79** |

### 5.2 Function path — cost of sales + qualitative description `{#s-5-2}`

If any operating line presents expenses classified by function: **§82**

- present a separate cost of sales line when functions include a cost-of-sales function — include IAS 2 inventory expense total;

- disclose a qualitative description of the natures included in each function line.

### 5.3 Function path — §83 single-note nature totals `{#s-5-3}`

Also disclose in a single note totals for: depreciation; amortisation; employee benefits; impairment losses/reversals (IAS 36); inventory write-downs/reversals — and for each total, the amount related to each operating line item plus any lines outside operating that also include amounts relating to that total. **§83**

> **Concept insight:** Design: solid containment plate for the §83 note (not dashed). Dashed stays rare (see-also only). **§83**

#### Worked example — function → nature totals note

- **Facts:** Entity presents COGS, distribution, and admin (function). Depreciation sits partly in COGS and partly in admin.
- **Concept / gate:** Function lines on P&L → §82 cost-of-sales + qualitative natures → §83 single note with depreciation total split by operating line. **§82–83**
- **Conclusion:** Function on face does not hide nature totals — the single note restores the nature lens investors need.

### 5.4 §84 exemption (thin — not a loophole essay) `{#s-5-4}`

Applying §83 exempts certain further nature↔function disaggregations beyond the §83 amounts — but does not waive other specific disclosure requirements in IFRS Accounting Standards. **§84–85**

> **Pitfall:** Reading §84 as permission to skip material disaggregation generally. §41 still requires material information; §84 is a narrow relief around the §83 package. **§41**, **§84–85**
